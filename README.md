# FirstMobileApplication

A simple beginner Android application built as my first hands-on project with **Android Studio, Kotlin, and Jetpack Compose**.

The purpose of this project is to get familiar with the Android development workflow, basic UI development, and user interaction.

## What I Practiced

* Creating and configuring an Android Studio project
* Working with **Kotlin**
* Building UI with **Jetpack Compose**
* Creating a basic interactive button
* Managing simple UI state
* Building the application with **Gradle**
* Using **Git and GitHub** for version control

## Features

* Simple centered UI
* Title: `My First Android App`
* Status message: `Android Studio is working!`
* Interactive `Click Me` button
* Button interaction updates the displayed message to `Button Clicked!`

## Built With

* **Kotlin**
* **Jetpack Compose**
* **Android Studio**
* **Gradle**
* **Git & GitHub**

## Project Purpose

This is my **first Android application**, created as a practical learning project while getting started with Android development.

The focus is intentionally small: understand the fundamentals, build something that works, and establish a clean development workflow.
